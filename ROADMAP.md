# Roadmap

Roughly ordered by priority

- Composable layout components (multiple parents, parent filter)
- Video playback parameters
- Configurable step animations
- `inkflow eject` copies a theme layout into the project and updates `deck.py` to point at the local copy.
- Watch-only mode (just rebuild, no server)
- Configurable keybindings: a `keybindings` dict on `Deck`
- Named theme support to find themes in pip packages
- Auto-advance: timed slides for kiosk or lightning-talk use
- Drawing and annotation mode
