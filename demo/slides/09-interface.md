# Try the interface

Press these keys right now:

| Key | Does |
|---|---|
| `?` | **show every shortcut** |
| `o` | overview of all slides |
| `p` | presenter view with notes |
| `t` | toggle light / dark |
| `g` | jump to a slide |
| `.` | laser pointer and freehand draw |

Open this same page in two windows — they stay in sync over WebSocket.
