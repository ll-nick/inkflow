# The Interface

::content align=center::

| Key | Does |
|---|---|
| `?` | open the help overlay |
| `o` | overview of all slides |
| `p` | presenter view with notes |
| `t` | toggle light / dark |
| `g` | jump to a slide |
| `.` | laser pointer and freehand draw |

\
Open this same page in two windows and they stay in sync over WebSocket.
