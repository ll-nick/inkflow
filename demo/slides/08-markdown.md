# Markdown, math & media

Write a slide in plain Markdown and drop in **math**:

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

Inline works too: $a^2 + b^2 = c^2$.

- Images and video embed straight into layout zones
- Everything is base64-inlined, so the output SVG is self-contained
- Swap the image path for an `.mp4` in `deck.py` and it just plays
