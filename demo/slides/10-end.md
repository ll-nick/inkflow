# Yours to bend

Everything is SVG, Markdown and Python, so nothing is a black box:

- **Custom animations** like the `Flicker` from earlier — a few lines of CSS
- **Custom transitions** like the `Flip` that just played — a small JS function
- Themes, layouts, HTML and PDF export, automatic font embedding, git-friendly diffs

**Get started:** `uv add inkflow` — [github.com/ll-nick/inkflow](https://github.com/ll-nick/inkflow)

*Early-stage software: the API will still change.*
