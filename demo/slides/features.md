# Features

**✏️ Draw in any SVG editor**  
Inkscape, Figma, anything that exports SVG: plain-text, diffable, no lock-in

**⌨️ Slides from Markdown**  
Reuse layouts and fill them with Markdown - including math and highlighted code

**🎨 Themable**  
Custom themes and layouts live in packages you can share and reuse

**📦 Portable**  
Export to plain HTML, all you need is a browser

**🧩 Expandable**  
Add your own animations, transitions, or even custom interactive widgets
